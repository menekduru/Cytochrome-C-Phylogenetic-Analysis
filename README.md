Cytochrome c Phylogenetic Analysis

A bioinformatics project investigating the evolutionary relationships among cytochrome c protein sequences from six vertebrate species using multiple sequence alignment, sequence conservation analysis, pairwise sequence identity, and Neighbor-Joining phylogenetic reconstruction.

Project Overview

Cytochrome c is a highly conserved mitochondrial protein involved in electron transport and cellular respiration. Because of its evolutionary conservation, cytochrome c provides a useful model for comparing protein sequences across species.

In this project, cytochrome c protein sequences from six vertebrate species were analyzed to investigate sequence conservation and evolutionary relationships.

The analyzed species were:

* Homo sapiens — Human
* Pan troglodytes — Chimpanzee
* Canis lupus familiaris — Dog
* Equus caballus — Horse
* Bos taurus — Cattle
* Gallus gallus — Chicken

Objectives

The project aimed to:

1. Perform multiple sequence alignment of cytochrome c protein sequences.
2. Identify conserved and variable amino acid positions.
3. Calculate pairwise sequence identity between species.
4. Construct a distance matrix from sequence identity.
5. Reconstruct a Neighbor-Joining phylogenetic tree.
6. Evaluate the robustness of inferred relationships using 1,000 bootstrap replicates.

Methods

1. Sequence Collection

Six cytochrome c protein sequences were obtained from the NCBI Protein database.

The original sequences are stored in:

data/cytochrome_c_sequences.fasta

2. Multiple Sequence Alignment

The six protein sequences were aligned to identify homologous amino acid positions and facilitate comparative analysis.

The resulting alignment contains:

* Alignment length: 105 amino acids
* Fully conserved positions: 87
* Variable positions: 18

The aligned sequences are stored in:

data/cytochrome_c_aligned.fasta

3. Sequence Conservation

Each alignment position was examined to determine whether the amino acid was conserved across all six species.

The analysis identified 87 fully conserved positions out of 105, corresponding to approximately 82.9% fully conserved sites.

The conservation results are available in:

results/conservation_results.txt

4. Pairwise Sequence Identity

Pairwise sequence identity was calculated between all six species.

Selected results include:

Species Pair	Sequence Identity
Human – Chimpanzee	100.00%
Dog – Cattle	97.14%
Horse – Cattle	97.14%
Human – Chicken	87.62%

The complete identity matrix is available in:

results/sequence_identity_matrix.csv

5. Neighbor-Joining Phylogenetic Reconstruction

Pairwise sequence distances were calculated from sequence identity and used to construct a Neighbor-Joining phylogenetic tree.

The resulting tree represents evolutionary relationships inferred from cytochrome c sequence similarity.

The phylogenetic tree is available in:

figures/cytochrome_c_phylogenetic_tree.png

6. Bootstrap Analysis

To evaluate the robustness of the inferred relationships, 1,000 bootstrap replicates were generated by resampling alignment columns with replacement.

For each replicate, a new distance matrix and Neighbor-Joining tree were constructed. Bootstrap support values were then calculated based on the frequency with which each clade appeared across the 1,000 replicate trees.

The strongest-supported relationship was:

Homo sapiens + Pan troglodytes — 100.0% bootstrap support

Other inferred clades showed lower support:

* Gallus gallus + Homo sapiens + Pan troglodytes: 60.0%
* Canis lupus familiaris + Gallus gallus + Homo sapiens + Pan troglodytes: 43.9%

The complete bootstrap results are available in:

results/bootstrap_support.txt

Results

The analysis revealed a high degree of conservation in cytochrome c across the six species.

87 of 105 alignment positions were fully conserved, corresponding to approximately 82.9% of the alignment.

Pairwise sequence identity was highest between human and chimpanzee, with 100.00% sequence identity in the analyzed cytochrome c sequences.

The Neighbor-Joining tree showed a close grouping of the human and chimpanzee sequences. This relationship received 100.0% bootstrap support across 1,000 replicates.

The deeper clades represented in the tree received lower bootstrap support (60.0% and 43.9%), indicating that these relationships were less consistently recovered across the bootstrap replicates.

Reproducibility

The complete analysis workflow is provided in:

analysis/cytochrome_c_phylogenetic_analysis.ipynb

The notebook contains the sequence analysis, conservation analysis, pairwise identity calculations, distance matrix construction, phylogenetic reconstruction, and bootstrap analysis used to generate the reported results.

The project is organized into separate directories for raw and processed data, analysis code, figures, and numerical results to make the workflow easier to follow and reproduce.

Conclusion

This project demonstrates a computational workflow for investigating evolutionary relationships using protein sequence data.

By combining multiple sequence alignment, sequence conservation analysis, pairwise sequence comparison, phylogenetic reconstruction, and bootstrap analysis, the project explores how computational methods can be used to study molecular evolution.

The analysis particularly demonstrated strong support for the grouping of Homo sapiens and Pan troglodytes, while also illustrating that deeper relationships in the reconstructed tree can have lower bootstrap support.
